# DSH 状态栏

独立的 Lexora 插件，借鉴 DSH 的状态展示方式，非 DSH 官方插件。在任务输入区下方将指标作为紧凑的一整组居中显示：

**1轮/13步 · 均速 tok/s | 总 Token · 缓存命中 | 上下文估算环与百分比**

## 安装与使用

需要 **Lexora 0.17.0 或更新的 0.x 构建，支持只读 `data` API、`context.usage` 和 `task.metrics.throughput`（均速与样本数）**。仅有版本号或 API 4 标记并不代表已包含这些能力；旧构建请先更新。

在 Lexora 插件管理中安装 `dist/dsh-status-1.0.3.lexora-extension`，确认作者为 `shanyuhai`，检查任务统计与上下文用量两项只读数据权限并启用。源码位于 `src/`，自包含 TypeScript，无需安装 npm 依赖。插件独立分发，不随 Lexora 安装包捆绑；`dist/` 保存本地打包产物，不纳入 Git。

当前版本为 **1.0.3**，补齐作者署名，并延续此前最高为 1.0.2 的测试包版本。插件 ID 保持不变；`dist/` 中的旧包仅用于历史追溯。

启用后自动显示，无设置页。主题与中英文跟随宿主；任务统计未就绪、无绑定或未授权时恢复原生输入区提示。上下文不可用时仅该项显示 —，其余任务统计照常显示。窄分屏会缩短标签；极窄时依次隐藏轮数/步数、速度和缓存率，优先保留总 Token 与上下文。完整数值与口径同时提供给辅助阅读工具。

## 数据范围

统计含义由 `task.metrics`（任务与分支统计）和 `context.usage`（角色上下文用量）两个公开数据源分别提供。插件通过 `data.observe` 的 `bound` 范围订阅当前视图绑定的数据，在本地组合显示；只有任务、分支标识一致的上下文才会展示，不拼接旧任务数据。

数据来源、读取接口与展示位置彼此独立：`composer.footer` 只是展示容器，不提供统计或自动授予数据权限。插件不读取任意任务、对话正文、父页面、文件或日志，不访问网络，不调用模型，不保存历史。

- **轮数**：当前分支可见的公开用户输入，包含 steer / follow-up。
- **模型步数**：实际已开始的 assistant 请求；失败或取消也计一步，不是工具调用次数。
- **总 Token**：输入、输出、缓存读取、缓存写入四桶之和。范围是该分支可见运行树，包含 NPC、工具及压缩消费，排除缓存预热与独立插件动作。
- **均速（累计平均输出速度）**：与宿主统计面板使用同一来源，按当前分支取有效样本的输出 Token 总数 ÷ 输出阶段总时长。已有历史计时可参与统计，成功完成且用量匹配才计入；样本数提供在辅助阅读说明中。不是瞬时速度，也不是整段对话的墙钟平均速度。内置面板默认显示全任务，范围不同可能导致数值不同。
- **缓存命中率**：缓存读取 ÷（输入 + 缓存读取 + 缓存写入）。分母为零时未知。
- **上下文**：宿主估算的上下文窗口占用，不是任务完成进度。圆环最多填满一圈，文本保留宿主返回的占比；估算可能与实际模型用量不同。

未知或无效数值显示 **—**，不以 0 代替。真实零用量正常显示 0；新任务仍可展示已知的轮数、Token 或上下文估算。数值可能使用 K/M/B 等紧凑单位；屏幕阅读说明保留完整数值。无瞬时速率、任务完成进度或跨窗口弹层。
